钉钉会话报告台 1.3.9——升级操作

1. 关闭旧版报告台的启动窗口。
2. 把新版压缩包完整解压到新文件夹，不要在压缩包里运行。
3. 如果要保留模型配置和历史报告，将旧版文件夹里的整个 data 文件夹复制到新版文件夹，合并并使用旧版同名文件。旧版文件夹先保留，不要删除。
4. 双击新版“02_日常启动.cmd”。缺少运行依赖时会自动安装，请保持窗口打开。
5. 浏览器按 Ctrl+F5 刷新，进入“大模型配置与测试”。
6. 使用 DeepSeek 官方接口时核对：
   接口协议：OpenAI Responses API
   Base URL：https://api.deepseek.com
   模型名称：deepseek-flash
   API Key：自己的 DeepSeek 官方 Key；已保存正确的 Key 可留空。
   超时：120；重试：1；Temperature：0.1；最大输出 Tokens：6000。
7. 点击“保存配置”，再点击“测试模型”，等待四项全部通过。
8. 核对“报告本人”为张三，按原来的方式选择聊天和时间、预览并手动生成。

如果旧版任务提示“模型 JSON 不符合证据候选结构”，升级后使用完全相同的会话、时间和报告要求重新创建任务。只要复制了完整 data 文件夹，新版会复用已通过严格校验的成功批次，仅补跑缺失部分。

说明：
- 原来的模型测试记录不能替代新版测试，升级后必须重新测试一次。
- 新版不会自动生成报告或读取聊天，也不会自动发送报告。
- 两份报告仍不显示引用原文和出处。
- 若尚未使用过此软件，请从“01_首次使用.cmd”开始，完整流程见“使用说明.txt”。
